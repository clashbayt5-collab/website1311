# Норильск: компании без сайта

Компании Норильска, Талнаха и Кайеркана, у которых нет собственного сайта, по данным 2ГИС и Яндекс.Карт (сбор: ноябрь 2026).

- **`index.html`** — каталог: выбор ниши, фильтры (район, приоритет, поиск), телефоны, ссылки на 2ГИС, Яндекс.Карты и соцсети. Для каждой ниши — сценарий звонка (краткий и полный), в карточке компании — персональный заход, жалобы из отзывов и сообщение после звонка. Открывается двойным щелчком в браузере.
- **`Норильск_компании_без_сайта.xlsx`** — та же выборка таблицей: сводка, общий лист и лист на каждую нишу.
- **`data/`** — сырые данные: `2gis.json`, `yandex.json`, итоговый `leads.json` и `reviews.json` (жалобы из отзывов Яндекса).
- **`scripts/call_scripts.json`** — тексты сценариев звонков по нишам, их можно править.
- **`scripts/`** — сбор и обработка.

## Что считается «без сайта»

Ни в 2ГИС, ни в Яндексе у компании нет собственного домена. Соцсети, мессенджеры, Taplink, онлайн-запись (DIKIDI, YCLIENTS), Avito и QR-меню сайтом не считаются. Исключены госучреждения, банки, федеральные сети и закрытые компании.

Балл 0–100: ценность сайта для ниши, число отзывов, рейтинг, активность в соцсетях, филиалы, присутствие на обеих картах. A (60+) — горячие, B (45–59) — тёплые, C — холодные.

## Обновить данные

Нужен Python 3 и `pip install requests openpyxl`.

```bash
cd scripts
python scrape.py yandex ../data
python scrape.py yandex ../data pass2
python scrape.py 2gis ../data pass2
python analyze.py ../data ../Норильск_компании_без_сайта.xlsx ../data/leads.json
python build_page.py ../data/leads.json template.html ../index.html call_scripts.json ../data/reviews.json
```

Сбор возобновляемый: уже пройденные запросы пропускаются. Чтобы собрать заново с нуля, удалите `data/2gis.json` и `data/yandex.json`.
